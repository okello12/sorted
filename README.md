# Sorted

One task for the whole journey: what you were about to do, the call, and what they promised.

The day before that promise is due, the task turns orange. Show it to the person in front of you. If they don’t show, it comes back to **Your move**.

Copy a link and someone else can open that one task. The rest of the list stays on your phone.

```bash
npm install
npm run dev
```
